# 63rd Street Crew Website

A responsive static website for the 63rd Street Crew roleplay community.

## Current pages
- Home
- Applications (front-end preview only; does not submit or store data)
- Chain of Command
- Gang Information
- Streets & Turf
- Media Gallery
- Member Portal placeholder

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy with Cloudflare Pages
1. In Cloudflare, open **Workers & Pages** and create a Pages project.
2. Choose **Connect to Git** and select this GitHub repository.
3. Use the `main` branch.
4. Framework preset: **None**.
5. Build command: leave blank.
6. Build output directory: `/`.
7. Deploy.

Cloudflare Pages will redeploy when new commits are pushed to `main`.

## Important
Application forms are deliberately demo-only. Do not collect real applications until a secure backend, validation, spam protection, data retention policy and authenticated leadership review are implemented. The member portal and leadership management are placeholders for a later phase. Discord integration is intentionally not included in this release.
